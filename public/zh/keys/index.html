在 Duaer 里获取调用密钥

Duaer 密钥用来调用 Duaer 数据接口。登录后创建。完整密钥只显示一次。

模型 API 密钥

  1. 打开 Duaer 登录。
  2. 进入 设置里的模型 API 密钥。
  3. 新建一把密钥，立刻复制。完整值只显示一次。
  4. 调用时放在请求头：Authorization: Bearer <Duaer key>。

账号密钥

管理员也可以在 管理里的 API 密钥 生成账号密钥。数据接口同样接受这把密钥。

问题

打开 Duaer 技能目录会扣额度吗？

不会。打开目录、复制技能都不检索，也不扣额度。真正调用成功才扣 1 额度。
